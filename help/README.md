# AVE.cms — документация

Справочник по компонентам движка. Разделы раскладываются по папкам — по одному
компоненту (или группе) на описание.

Название системы — **AVE.cms**. В документации слова «панель управления» и
«админка» обозначают административный интерфейс AVE.cms. `adminx/` — имя его
технического каталога по умолчанию и часть внутренних имён API, а не название
отдельного продукта. Каталог можно переименовать при установке или позднее.

## Соглашения

- Код совместим с **PHP 7.3** (без стрелочных функций, `??=`, типизации свойств и т. п.).
- Классы ядра и установленных модулей подключаются штатным загрузчиком; ручные `require` для классов не нужны.
- Почти все хелперы — **статические** (`Helper::method()`), состояние не хранят.
- Пути к файлам приложения стройте относительно `BASEPATH`, не привязываясь к
  расположению проекта на конкретном сервере.

Документация описывает поддерживаемые контракты движка. Непубличные детали
реализации могут меняться между версиями.
