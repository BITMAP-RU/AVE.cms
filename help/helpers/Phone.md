# Phone

← [К хелперам](README.md)

`App\Helpers\Phone` приводит пользовательский ввод к единому телефонному
формату. Хелпер не отправляет SMS и не работает с пользователями.

```php
use App\Helpers\Phone;
```

| Метод | Результат |
| --- | --- |
| `normalize($value)` | Международный номер с `+` или пустая строка. |
| `valid($value)` | Проходит ли номер базовую E.164-проверку. |
| `digits($value)` | Только цифры нормализованного номера. |
| `mask($value)` | Безопасное значение для интерфейса и аудита. |

```php
$phone = Phone::normalize('8 (900) 123-45-67');
// +79001234567

$masked = Phone::mask($phone);
// +7******4567
```

Российские номера из 10 цифр получают код `+7`; ведущая `8` заменяется на
`+7`. Остальные номера должны соответствовать международному формату: от 10 до
15 цифр, первая цифра не ноль.
