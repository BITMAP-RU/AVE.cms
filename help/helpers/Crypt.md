# Crypt — шифрование строк

`App\Helpers\Crypt` — обратимое шифрование строк и мелкие преобразования.

```php
use App\Helpers\Crypt;
```

---

## Методы

### `_crypt($string)` / `_decrypt($string)`
Зашифровать / расшифровать строку (парные операции).
```php
$token = Crypt::_crypt($payload);
$data  = Crypt::_decrypt($token);   // исходное значение
```

### `crc32($value)`
CRC32-хеш значения (быстрая контрольная сумма, **не** для безопасности).
```php
$key = 'cache_' . Crypt::crc32($sql);
```

### `convert64b32($int)`
Конвертация основания числа (64 ↔ 32) — для компактных идентификаторов.

---

## Когда что использовать

| Задача | Инструмент |
| --- | --- |
| Обратимо спрятать значение (токен, payload) | `Crypt::_crypt()` / `_decrypt()` |
| Хеш строки (сравнение, ключ кеша) | `Str::sha256()` / `Crypt::crc32()` |
| **Пароли** | `password_hash()` / `password_verify()` — **не** `Crypt` |
| Подпись/сравнение секретов | `Str::equals()` (timing-safe) |

> `_crypt`/`_decrypt` подходят для служебных данных, но это не замена полноценному
> шифрованию секретов на уровне инфраструктуры.
