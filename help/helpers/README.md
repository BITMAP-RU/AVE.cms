# Хелперы фреймворка

Набор статических утилит из `system/App/Helpers/`. Почти все методы —
`Helper::method()` (состояние не хранится). Классы автозагружаются, `use` обычно не
требуется, если код в том же неймспейс-контексте; иначе — `use App\Helpers\Str;`.

## По категориям

### Строки, массивы, числа, дата
| Хелпер | Назначение |
| --- | --- |
| [Str](Str.md) | Работа со строками в UTF-8 (mbstring): регистр, обрезка, slug, camel/snake, маскирование, UUID. |
| [Arr](Arr.md) | Массивы: `get/set` по dot-нотации, поиск, сортировка, объект↔массив, безопасная (де)сериализация. |
| [Number](Number.md) | Форматирование чисел, размеров, склонения, число прописью, сравнение float. |
| [Date](Date.md) | Дата/время: SQL↔timestamp, человекочитаемый формат, склонения. |
| [Locales](Locales.md) | Локаль, транслитерация, перевод и «красивый» вывод дат. |

### HTTP: запрос и ответ
| Хелпер | Назначение |
| --- | --- |
| [Request](Request.md) | Доступ к входящим данным: GET/POST/JSON, типизированные геттеры, метод, AJAX, IP. |
| [Response](Response.md) | Ответы: JSON/HTML/текст/XML, скачивание, коды 204/404/403/401/422/429/500. |
| [Cookie](Cookie.md) | Чтение/запись/удаление cookie. |
| [Url](Url.md) | Построение ссылок, редиректы, canonical, rewrite, referer. |
| [Ip](Ip.md) | Определение и валидация IP, гео-данные, ip↔hex. |
| [Phone](Phone.md) | Нормализация, проверка и безопасное маскирование телефонных номеров. |

### Безопасность и валидация
| Хелпер | Назначение |
| --- | --- |
| [Valid](Valid.md) | Валидация: статические проверки и пакетная `check($data, $rules)`. |
| [Secure](Secure.md) | Очистка ввода от XSS, санитайз, обработка телефонов. |
| [Crypt](Crypt.md) | Шифрование/дешифрование строк, crc32, конвертация основания. |

### Файлы и каталоги
| Хелпер | Назначение |
| --- | --- |
| [File](File.md) | Файлы: чтение/запись (в т. ч. атомарная), mime, скачивание, кодировки, имена. |
| [Dir](Dir.md) | Каталоги: создание, обход, размер, копирование, права. |

### Данные, вывод, разное
| Хелпер | Назначение |
| --- | --- |
| [Json](Json.md) | Безопасные encode/decode, payload для API, работа с кириллицей, «починка» JSON. |
| [Html](Html.md) | Сжатие HTML, gzip-вывод, nl2br, encode/decode, query-строки. |

### Контент и текст
| Хелпер | Назначение |
| --- | --- |
| [TagParser](TagParser.md) | Разбор тегов в шаблонах/контенте, регистрация обработчиков. |
