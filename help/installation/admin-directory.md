# Папка панели управления

← [К разделу «Установка»](README.md)

При чистой установке можно выбрать имя каталога панели управления. Поле уже
заполнено значением `adminx`; его можно оставить без изменений или задать своё,
например `control` или `site_admin`.

Имя должно начинаться с латинской буквы, может содержать латинские буквы,
цифры, `-` и `_` и быть не длиннее 48 символов. Имена системных каталогов,
включая `system`, `modules`, `setup`, `storage` и `uploads`, использовать нельзя.

Установщик выполняет операцию целиком:

1. Проверяет, что выбранный каталог свободен и корень сайта доступен для записи.
2. Переименовывает исходный каталог `adminx`.
3. Записывает имя в `configs/public.config.php` как `admin_directory`.
4. Возвращает в браузер правильную ссылку входа.

Если финальный этап установки завершается ошибкой, каталог и конфигурация
возвращаются в исходное состояние.

## Переименование после установки

Перед изменением сделайте резервную копию файлов и включите режим обслуживания.
Затем:

1. Переименуйте физический каталог панели, например `adminx` в `control`.
2. В `configs/public.config.php` задайте то же имя:

```php
'admin_directory' => 'control',
```

3. Откройте `/control/login` и проверьте вход, ресурсы интерфейса, установку
   модулей и ссылку быстрого редактирования на публичном сайте.

Реестр модулей сам обнаружит изменение корневого каталога и пересоберёт свою
секцию. Удалять его вручную не требуется.

## Веб-сервер

Поставляемый `.htaccess` панели не содержит фиксированного `RewriteBase`, поэтому
на Apache продолжает работать после переименования. При собственной конфигурации
веб-сервера направляйте несуществующие URL внутри выбранного каталога в его
`index.php`, разрешайте прямую отдачу assets и запрещайте выполнение остальных
PHP-файлов панели через HTTP.

Скрытое имя не заменяет авторизацию и права. AVE.cms дополнительно отправляет для
страниц панели `X-Robots-Tag: noindex, nofollow, noarchive`.
