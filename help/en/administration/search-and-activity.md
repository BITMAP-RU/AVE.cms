# Search, commands, and activity

← [Back to system administration](README.md)

## Command palette

Use the search button in the top bar or press `Ctrl+K` (`Cmd+K` on macOS).
The palette lists available sections and searches actual administrative
objects.

It searches documents, rubrics, directories, blocks, queries, and navigation
items by title, URL, or ID. Results respect the current user permissions and
open the regular editor without saving anything automatically.

## Activity timeline

Open **System → Events → Activity**. The technical audit is presented as a
readable timeline: who performed an action, when it happened, and which object
was affected. A known object links to its regular editor.

The **Audit** tab keeps the technical representation with action codes,
metadata, and export. Both views use the same audit table and do not duplicate
data.
