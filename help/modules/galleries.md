# Галереи

← [Назад к разделу «Модули»](README.md)

Модуль `galleries` собирает изображения общей медиатеки в управляемые коллекции.
Файлы не копируются: галерея хранит URL, подписи, порядок и настройки вывода.
Поддерживаются сетка и слайдер, WebP и разрешённые пресеты миниатюр.

## Вставка и публичная страница

```text
[mod_gallery:3]
```

Число — ID опубликованной галереи. Для самостоятельной страницы используется
URL `/galleries/<alias>`; базовая часть меняется в настройках. На странице
работает пагинация `gpage`, а вставочный тег выводит коллекцию целиком.

## Теги шаблона галереи

| Тег | Значение |
| --- | --- |
| `[tag:id]` | ID галереи. |
| `[tag:title]` | Экранированное название. |
| `[tag:description]` | Готовое описание либо пустая строка. |
| `[tag:mode]` | Режим `grid` или `slider`. |
| `[tag:columns]` | Настроенное число колонок. |
| `[tag:items]` | Собранные изображения в заданном порядке. |
| `[tag:count]` | Число элементов текущего вывода. |
| `[tag:pagination]` | Навигация публичной страницы. |

## Теги изображения

| Тег | Значение |
| --- | --- |
| `[tag:id]` | ID элемента галереи. |
| `[tag:index]` | Индекс в текущей выдаче, начиная с `0`. |
| `[tag:source]` | URL исходного файла для лайтбокса. |
| `[tag:thumb]` | URL миниатюры выбранного пресета. |
| `[tag:webp]` | URL связанного WebP-исходника либо пустая строка. |
| `[tag:picture]` | Готовый `<picture>`/`<img>` с lazy loading. |
| `[tag:title]` | Экранированный заголовок. |
| `[tag:alt]` | Alt-текст; при пустом значении используется title. |
| `[tag:description]` | Готовая подпись либо пустая строка. |
| `[tag:link]` | Дополнительная проектная ссылка элемента. |

Штатный лайтбокс использует `data-gallery`, `data-gallery-items`,
`data-gallery-item`, `data-gallery-open` и `data-gallery-index`. Для полностью
собственного JavaScript эти атрибуты можно заменить вместе с assets темы.

Миниатюра строится только через разрешённый preset. Если генератор не может
создать её, renderer безопасно использует URL исходника. Для WebP создаётся
отдельный `<source>` только когда связанный файл существует.
Новая галерея по умолчанию получает первый пресет из системного белого списка;
после изменения списка недоступные старые значения нормализуются миграцией
модуля.

## API и hook

```text
GET /api/v1/galleries/3
```

JSON содержит настройки коллекции и элементы: `file_url`, `webp_url`, title,
alt, description, link и status. HTML в API не навязывается, поэтому endpoint
подходит для своего слайдера или мобильного клиента.

Фильтр `galleries.rendering` получает массив `gallery` и готовый `html`.
Удаление галереи очищает её записи, но не удаляет исходники и миниатюры общей
медиатеки.
