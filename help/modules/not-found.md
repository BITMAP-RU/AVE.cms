# Ошибки 404

← [Назад к разделу «Модули»](README.md)

Модуль `notfound` записывает реальные публичные ответы 404: запрошенный URL,
источник перехода, число повторов и время последнего обращения. Он помогает
отличать потерянные внутренние ссылки от случайного сканирования.

## Работа с журналом

1. Откройте **Модули → Ошибки 404**.
2. Отфильтруйте нерешённые строки и отсортируйте работу по числу повторов.
3. Для ценного старого URL найдите существующий документ и создайте редирект.
4. Ненужный адрес отметьте решённым или удалите.
5. Периодически очищайте решённые записи.

Создание редиректа добавляет штатное правило перенаправления и отмечает событие
решённым. Не перенаправляйте все неизвестные URL на главную: это скрывает
ошибки, создаёт неинформативные ответы и мешает поисковым системам.

Права:

- `view_notfound` — просмотр журнала;
- `manage_notfound` — редиректы, статусы и очистка.

Для создания редиректа дополнительно требуется `manage_documents`, поскольку
правило записывается в историю URL выбранного документа.

В список попадает только итоговая публичная 404, а не каждый промежуточный поиск
маршрута. Деинсталляция удаляет журнал; созданные штатные редиректы остаются
частью контента и не удаляются вместе с модулем.
