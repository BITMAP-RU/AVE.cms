# SEO-аудит

← [Назад к разделу «Модули»](README.md)

Модуль `seoaudit` проверяет опубликованные документы и группирует сигналы по
метаданным, URL, индексированию и служебным настройкам. Основной аудит работает
только на чтение и рассчитывается по текущей БД.

## Что проверяется

- наличие, ориентировочная длина и дубли `title` и `description`;
- повторение title в description и HTML внутри description;
- пустой, некорректный, длинный или неровный alias;
- заглавные буквы и подчёркивания в URL;
- `noindex`, `nofollow` и истёкший срок публикации;
- исключение документа из внутреннего поиска;
- отсутствие ключевых слов для внутреннего поиска.

Длины title 10–65 и description 50–160 символов являются ориентирами, а не
гарантированными требованиями поисковых систем. Служебные замечания не уменьшают
SEO-балл. Список интерфейса ограничен 300 проблемными документами, но сводные
счётчики рассчитываются по всему проверенному набору.

## Автозаполнение

Для документа можно сначала открыть предложение без записи, затем заполнить
метаданные. Модуль записывает только пустые `description` и `keywords` и не
перетирает ручную работу. Пакетная операция обрабатывает до 200 документов за
запуск; при остатке её можно повторить.

После применения очищаются связанные кеши документа. Перед массовым заполнением
проверьте предложения на нескольких документах разных рубрик.

Права:

- `view_seoaudit` — отчёт и виджет главной;
- `manage_seoaudit` — предложение и запись метаданных.

Модуль не отправляет данные во внешние SEO-сервисы и не проверяет позиции,
индексацию поисковиком, sitemap или фактический HTML после клиентского JavaScript.
