# Всплывающие окна

`popups` управляет кампаниями всплывающих окон, A/B-вариантами и заявками.
Кампания задаёт пути страниц, период активности, частоту повторного показа и
один из сценариев: задержка, процент прокрутки или попытка ухода со страницы.

HTML вариантов A и B хранится отдельно. Доля варианта B настраивается в
процентах; один посетитель стабильно получает тот же вариант. В HTML доступны:

| Тег | Значение |
| --- | --- |
| `[tag:csrf]` | CSRF-токен публичной формы. |
| `[tag:campaign-id]` | ID кампании. |
| `[tag:variant-id]` | ID выбранного варианта. |

Форма внутри варианта может содержать `name`, `email`, `phone` и дополнительные
поля. Для статуса ответа добавьте элемент с `data-popup-status`. Показ,
конверсия и заявка учитываются отдельно. Частота хранится в браузере посетителя.

Автоматическую вставку перед `</body>` можно выключить в настройках модуля.
Тогда модуль не меняет публичный HTML.
