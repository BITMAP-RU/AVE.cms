# Справочники

← [К разделу «Как собирается сайт»](README.md)

Справочник — это общий управляемый список значений для полей. Он не является
рубрикой, не создаёт документы и не имеет URL, SEO, шаблонов или прав публикации.

Примеры: страны, производители, материалы, типы учреждений, единицы измерения и
состояния обращения.

## Когда использовать

| Задача | Подходящий источник |
| --- | --- |
| Небольшой список только для одного поля | Локальный список поля |
| Общий список для разных рубрик | Справочник |
| Полноценная связанная сущность со своей страницей | Документы рубрики |

Используйте справочник, если один и тот же список нужен в нескольких рубриках
или полях. Если выбранная сущность должна иметь собственную страницу, URL,
изображения и другие поля, используйте связь с документами рубрики.

## Создание

1. Откройте **Рубрики и поля → Справочники**.
2. Нажмите **Создать справочник**.
3. Укажите понятное название. Технический код можно оставить пустым: система
   сформирует его автоматически.
4. Откройте созданный справочник и добавьте значения.

Каждое значение содержит:

- **подпись** — текст для редактора и посетителя;
- **стабильный ключ** — значение, которое хранится в документе;
- **порядок** — место строки в списке;
- **состояние** — доступность значения для нового выбора.

Ключ лучше не менять после начала работы. Подпись можно переименовывать свободно:
документы продолжат хранить тот же ключ.

## Подключение к полю

1. Откройте конструктор полей нужной рубрики.
2. Выберите поле типа «Выбор из списка», «Выпадающий список» или
   «Множественный выбор».
3. В настройке **Источник значений** выберите **Общий справочник**.
4. Выберите справочник и сохраните схему рубрики.

Формат значения документа не меняется. Одиночное поле хранит строковый ключ,
множественное — массив ключей в своём обычном формате. Поэтому переключение
источника не требует изменения публичных шаблонов.

## Удаление и отключение

Справочник нельзя удалить, пока он подключён к полям. Сначала назначьте этим
полям другой источник.

Отключённое значение исчезает из нового выбора, но его подпись сохраняется у
уже заполненных документов. При физическом удалении строки документ сохраняет
ключ; если подписи больше нет, AVE.cms выводит сам ключ вместо потери данных.

Старые справочники, созданные как рубрики с документами, продолжают работать.
Новые простые списки следует создавать в этом разделе.
