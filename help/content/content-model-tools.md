# Инструменты модели контента

← [К разделу «Как AVE.cms собирает сайт»](README.md)

Эти инструменты помогают собирать структуру сайта без копирования одинаковых
полей и ручного PHP.

## Справочники

Справочник — обычная рубрика специального назначения. Её документы являются
значениями списка: брендами, городами, авторами, типами оборудования и другими
повторно используемыми сущностями.

1. Откройте **Рубрики и поля → Справочники** и создайте справочник.
2. В редакторе рубрики добавьте поля значения.
3. Создайте документы справочника.
4. В рабочей рубрике добавьте поле **Документ из рубрики** и выберите
   справочник источником.

Справочник использует штатные рубрики, документы, права, API и ревизии
AVE.cms. Признак `directory` только отделяет его в панели от новостей, страниц
и товаров.

## Двусторонние связи документов

Поле связи хранит выбранный документ в исходном документе. AVE.cms параллельно
обновляет индекс, поэтому редактор показывает два направления:

- **Ссылается на** — документы, выбранные в полях текущего документа;
- **Ссылаются сюда** — документы, в которых выбран текущий документ.

Обратное значение вычисляется из индекса и не записывается вторым полем.
Поэтому стороны не расходятся после редактирования.

## Вычисляемые поля

Вычисляемое поле собирает значение из других полей документа.

| Режим | Пример |
| --- | --- |
| Текст | `{{ brand }} {{ model }}` |
| Формула | `(price * quantity) - discount` |

Формула поддерживает числа, alias полей, скобки и `+`, `-`, `*`, `/`. PHP-код
и функции не выполняются. Деление на ноль, неизвестный alias и неверная
формула возвращают указанное в настройках резервное значение.

Значение пересчитывается перед предпросмотром и сохранением, затем хранится как
обычное поле. Старые шаблоны, запросы, экспорт и API получают готовое значение.

## Библиотека готовых наборов

Набор — заранее описанная группа полей для типовой задачи: статья, новость,
карточка сотрудника, SEO или характеристики товара.

- **Копия** создаёт обычные независимые поля.
- **Связанный набор** запоминает источник и позволяет явно синхронизировать
  последующие изменения.

Перед применением показываются состав и конфликты alias. Существующие поля не
перезаписываются молча. После применения проверьте порядок, ширину и
обязательность полей в конструкторе рубрики.

## Совместимость

Публичные шаблоны не переключаются автоматически: справочник остаётся
рубрикой, связь и вычисление остаются полями, а набор только создаёт обычные
поля. Инструменты можно внедрять постепенно на отдельных рубриках.
